# Generation components

- `bootstrap.py`: load and sample released priors.
- `prior_source.py`: supply graph inputs from priors and authored policies.
- `profiles.py`: select the manufacturing or staffing graph.
- `authored/`: construct opening balances and asset registers.
- `subledgers.py`: build transaction populations.
- `projection/`: render workbooks and text documents.

Accounting rules and graph execution live in [../graph/](../graph/).
